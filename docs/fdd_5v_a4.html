ATmega328P（5V・16MHz）⇔ 34ピンFDD 配線表

Arduino Nanoの代わりにATmega328P単体（DIP-28）を5V・16MHzで使う。ArduinoFDC／fdd_test.ino と同じピン割当（書き込み時のボード設定は「Arduino Uno」）。 FDDとは直結（レベル変換IC不要）。FDDの信号はすべてアクティブLOW。

① チップのピン配置（上から見た図）

切り欠き（半円）と●印の側が1番ピン。青＝チップ→FDD、橙＝FDD→チップ。

入力のうちRDATA以外はチップ内蔵プルアップで可。WGATEの10kΩは、リセット中にピンが浮いて誤って書き込まれるのを防ぐため。 線番は、M/B側コネクタを切り落とした切り口で赤線＝1番。FDDはねじれの先の端コネクタに挿す。

③ 電源

  • 外部 5V 2A から、FDD電源とチップの7番・20番へ
  • FDD電源（小型4ピン）：赤＝+5V、黒＝GND（黄の12Vは不要）
  • 5Vラインに100µFを1個
  • GNDはすべて共通（電源、チップ、FDDの奇数線、Uno）

⑤ 注意

  • チップの17〜19番はISP書き込みにも使う。ブートローダーはFDDをつなぐ前に書き込む
  • ヒューズを書き換えた後は水晶がないと動かない。水晶と22pFを確認してから書き込む
  • 最初の書き込みテストは、消えてもいいディスクで

⑦ 手順

  1. UnoにArduinoISPを書き込み、UnoのRESET–GNDに10µFを入れる
  2. チップに水晶・コンデンサ・5V・GNDを付け、ISPの配線をする
    Uno D10→1番、D11→17番、D12→18番、D13→19番
  3. ボード「Arduino Uno」、書込装置「Arduino as ISP」で「ブートローダーを書き込む」
  4. ISPの配線を外し、②〜④のとおりFDDとUSBシリアルをつなぐ
  5. fdd_test.ino で、モーター・シーク・回転数（約300rpm）を確認
  6. ArduinoFDCを書き込んで、ディスクの読み書き
