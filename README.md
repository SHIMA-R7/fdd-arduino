# 34ピンFDD × ATmega328P

PC用の34ピンフロッピーディスクドライブを、Arduinoボードを使わず **ATmega328P単体（5V・16MHz）** で動かすための配線資料とスケッチ一式です。読み書きには [ArduinoFDC](https://github.com/dhansel/ArduinoFDC)（David Hansel作）を使います。このリポジトリには、そこに至るまでの配線図、動作確認用スケッチ、診断用スケッチ、そして**ドライブを楽器として鳴らすためのツール**が入っています。

## できること

- FDDのモーター制御、ヘッドのシーク、トラック0検出、面切替、回転数測定
- ArduinoFDCによるセクタ単位の読み書きとフォーマット
- ステッピングモーターを使った音階演奏、MIDIファイルの再生

## 配線

ピン割り当てはArduinoFDCのUno/Nano用と同じです。**A4に印刷できる配線表**を `docs/` に置いてあります。

| FDD線番 | 信号 | 向き | Arduino | ATmega328P DIPピン | 追加部品 |
|---|---|---|---|---|---|
| 2 | /DENSEL | 出力 | D13 | 19 | |
| 8 | /INDEX | 入力 | D7 | 13 | |
| 10 | /MOTEA | 出力 | D4 | 6 | |
| 12 | /DRVSB | 出力 | A1 | 24 | |
| 14 | /DRVSA | 出力 | D5 | 11 | |
| 16 | /MOTEB | 出力 | A0 | 23 | |
| 18 | /DIR | 出力 | D3 | 5 | |
| 20 | /STEP | 出力 | D2 | 4 | |
| 22 | /WDATA | 出力 | D9 | 15 | OC1A固定 |
| 24 | /WGATE | 出力 | D10 | 16 | 10kΩで5Vへ |
| 26 | /TRK00 | 入力 | D11 | 17 | |
| 28 | /WPT | 入力 | D12 | 18 | |
| 30 | /RDATA | 入力 | D8 | 14 | **1kΩで5Vへ** |
| 32 | /SIDE1 | 出力 | D6 | 12 | |
| 34 | /DSKCHG | 入力 | A2 | 25 | |
| 奇数線すべて | GND | | GND | 8, 22 | 束ねる |

- D8（RDATA）とD9（WDATA）はタイマーの専用ピンなので変更できません。
- FDDの信号はすべてアクティブLOWです。奇数番の線はすべてGNDです。
- ケーブルはマザーボード側のコネクタを切り落とし、FDDは**ねじれの先の端コネクタ**に挿します。こうすると切り口の線番がそのままピン番号になります（`docs/fdd_pinout_a4.pdf` を参照）。
- 電源は外部5V（2A程度）を使い、FDDとマイコンのGNDを共通にします。

### 必要な部品

ATmega328P、16MHz水晶と22pF×2、0.1µF×3、電解100µF、抵抗10kΩ×2と1kΩ×1、タクトスイッチ、USBシリアル変換器、5V電源。

## スケッチ

| スケッチ | 用途 |
|---|---|
| `sketches/fdd_test` | 動作確認。シリアルからモーター、シーク、回転数測定などを操作 |
| `sketches/nano_selftest` | マイコン単体の自己診断（ピンの出力/プルアップ/ピン間ショート/電源電圧） |
| `sketches/fdd_music` | 単体で音階やデモ曲を鳴らす |
| `sketches/fdd_play` | PCから `F<周波数>` を受けて鳴らし続ける（曲の再生用） |

ボード設定は **Arduino Uno** を選びます。

## MIDIの再生

```
python tools/extract_mel3.py <MIDIファイル> <出力.json> <主旋律ch> <代役ch> <上限Hz>
powershell -File tools/play.ps1 -Json <出力.json> -Port COM7
```

例：

```
python tools/extract_mel3.py song.mid song.json 0 "1,3,4" 880
powershell -File tools/play.ps1 -Json song.json
```

- MIDIを単音のメロディに変換します。主旋律のチャンネルを基本とし、そこが1.5秒以上休む区間（イントロを含む）だけ代役チャンネルに渡します。
- ドライブが鳴らせる範囲に収めるため、上限（既定880Hz）を超える音はオクターブ下げます。
- 音符間の短い無音（120ms以下）は前の音に吸収して、途切れを防いでいます。
- MIDIファイルは含めていません。手持ちのものを使ってください。

## ハマりどころ

実際に詰まった箇所です。

- **ArduinoFDCは16MHz専用**。ソースに `#error "ArduinoFDC library requires 16MHz clock speed"` があります。読み書きの処理は16MHzの命令サイクルを数えたアセンブラで書かれているため、8MHzでは動きません。3.3Vで16MHzはデータシートの定格外（3.3Vでの上限は約13MHz）なので、5Vで動かします。
- **水晶の22pFは直列ではなくGNDへ**。水晶を9番・10番ピンに直結し、22pFはそれぞれの足からGNDに落とします。直列に入れると発振しません。
- **34ピンコネクタを逆向きに挿すと、信号線とGND線が入れ替わります**。入力がすべてLOWに見え、出力はGNDに短絡します。
- **DTRのないUSBシリアル変換器では自動リセットが効きません**。avrdudeをループで再試行させ、その間に手でリセットを押します。ArduinoFDCは `#define USE_ARDUDOS` を外すと29KB→13.6KBに縮み、書き込み時間が半分になって成功しやすくなります。
- **日本の「フォーマット済み2HD」はPC-98系の256フォーマット（360rpm・500kbps）の場合があります**。300rpmの3.5インチドライブでは原理的に読めません。パルス間隔を測ると、本来2/3/4µsのところが2.4/4.8µsに伸びて観測されます。
- **楽器化でのタイミング**：PowerShellの `Start-Sleep -Milliseconds 1` は実際には約15ms眠ります。目標時刻の直前はスピン待ちにしないとリズムが崩れます。

## 謝辞

読み書きの本体は [ArduinoFDC](https://github.com/dhansel/ArduinoFDC)（David Hansel）によるものです。16MHzで500kbpsのMFMを処理する実装がなければ、この工作は成立しませんでした。
